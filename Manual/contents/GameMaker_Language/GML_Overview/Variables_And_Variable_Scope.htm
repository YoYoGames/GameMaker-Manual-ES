Variables y alcance de las variables

Como cualquier lenguaje de programación, GML utiliza variables como unidad básica para la mayoría de las operaciones de programación. Las variables se utilizan para almacenar información en la memoria de los dispositivos para su uso posterior (o instantáneo), y se les da un nombre para poder referirse a ellas en runtime y en las funciones de script. Una variable en GML puede almacenar muchos datos diferentes tipos de datoscomo un número real (p. ej.: 100, 2,456575, -56, etc.), un string (p. ej.: "¡Hola mundo!"), un número entero (p. ej.: 1, 556, -7), o un booleano (true o false), así como otras cosas:

var _num = 126.4545;
var _str = "Hello World";
new_num = _num * 100;
global.my_string = _str + " I said";

También se pueden utilizar variables para mantener los valores devueltos por las funciones, por ejemplo:

var _id = instance_nearest(x, y, obj_Tree);
root = sqrt(1000);
global.str = string_upper("Hello World");

Así pues, una variable es algo que podemos nombrar y utilizar para almacenar un valor para utilizarlo posteriormente en una o varias operaciones. Un gran ejemplo del "mundo real" de una variable es pi 𝜋 . .. es una variable que todo el mundo conoce y contiene el valor 3,14159265(etc...). ¿Por qué la tenemos en nuestro idioma? Bueno, es mucho más fácil decir a alguien "pi" que "tres punto uno cuatro uno cinco nueve dos seis cinco". Nombrar las cosas así simplifica mucho la vida y también significa que si el valor de esa variable cambia alguna vez, no tenemos que cambiar el número en todas partes, ya que el nombre de la variable sigue siendo el mismo.

Cuando se forman variables en GML deben tener un nombre que empiece por una letra o el símbolo de subrayado "_" y sólo pueden contener letras, números y el símbolo de subrayado '_' con una longitud máxima de 64 símbolos. Así, las variables válidas son cosas como fish, foo_bar, num1, o _str, mientras que las variables no válidas serían 6fish, foo bar, o *num.

Ahora bien, en muchos lenguajes de programación es necesario crear una "asignación" de variable antes de poder utilizarla. Esto significa básicamente que le dices al ordenador el nombre que deseas utilizar para la variable y le asignas un valor inicial. A continuación, se asigna a la variable un lugar en la memoria para almacenar el valor o realizar operaciones con ella. La asignación de una variable tiene la forma de:

<variable> = <expression>;

Una expresión puede ser un simple valor, pero también puede ser más complicada, por lo que, en lugar de asignar un valor a una variable, también se puede añadir un valor al valor actual de la variable utilizando +=, por ejemplo:

a = 100;   // Assigning a simple value
b = 200;
c = 300;
a += b;    // Assigning with operation
a = b + c; // Assigning with expression

NOTA El GameMaker Language también aceptará ":=" para las asignaciones, aunque no suele ser la forma más habitual de hacerlo:

<variable> := <expression>;

Del mismo modo, puede restar utilizando -=, multiplicar utilizando *=, dividir utilizando /=, o utilizar operadores a nivel de bits utilizando |=, &=, o ^=. También puede sumar o restar uno de un valor utilizando ++, --. Para más información, consulte la sección Expresiones y operadores.

Tenga en cuenta que no puede hacer lo siguiente (o cualquier variación):

a = b = c = 4;

Y en su lugar debería hacerse como:

a = 4;
b = 4;
c = 4;

Las asignaciones de variables mostradas arriba son todas variables de instancia , sin embargo hay otras tres categorías principales de variables cuando se programa con GameMaker y cada una tiene su propio alcance (que puede ser considerado como su área de operación, o alcance). Los diferentes tipos de variables y su alcance se describen en las siguientes páginas:

  • Variables locales
  • Variables de instancia
  • Variables globales
  • Constantes

El GameMaker Language también tiene múltiples y diferentes variables incorporadas que pueden tener cualquiera de los alcances antes mencionados (excepto local). Estas variables son especiales, ya que se incluyen por defecto como parte del objects y del rooms en el mundo del juego. Algunas variables globales incorporadas se enumeran en la sección mencionada anteriormente, y las diferentes partes del manual para sprites, rooms, objects, etc... también describen las variables incorporadas disponibles en cada caso. Ejemplos de estas variables de instancia incorporadas serían:

  • sprite_index
  • path_scale
  • speed

Y ejemplos de variables globales incorporadas serían:

  • view_xport
  • GM_version
  • room

La mayoría de las variables incorporadas pueden cambiarse y establecerse como otras variables, y algunas incluso pueden ser matrices, sólo que no tienes que establecerlas para crearlas como lo harías con una variable normal, ya que ya estarán inicializadas con un valor por defecto.
